Grafik Beban Crane (Tabel Kapasitas Angkat) untuk Keselamatan Kerja

Apa itu Load Chart?

Load Chart menunjukkan Safe Working Load / SWL (Beban Kerja Aman) crane untuk kombinasi:

  • Boom length (panjang boom)
  • Radius / working distance (jari-jari kerja)
  • Boom angle (sudut boom)
  • Configuration (konfigurasi: outrigger, counterweight, jib)

Menggunakan Load Chart mencegah overloading (kelebihan beban) dan kecelakaan crane.

Dalam bahasa sederhana

Load Chart seperti panduan keselamatan untuk crane Anda. Ini memberitahu berat maksimum (beban) yang boleh diangkat pada berbagai panjang boom dan sudut.

Bagaimana cara membaca Load Chart?

  1. 1. Temukan Boom Length
    Pilih panjang boom aktual yang dipakai.
  2. 2. Temukan Working Radius
    Jarak horizontal dari pusat putar ke beban.
  3. 3. Baca SWL / Beban Kerja Aman
    Nilai persimpangan baris dan kolom = beban maksimum.
  4. 4. Periksa Boom Angle
    Sudut boom harus sama atau lebih besar dari chart.

Contoh penggunaan

Boom Length 22.0 m · Working Radius 20 m · Boom Angle 60°

SWL = 6.2 TON

Jika diabaikan

  • ✗ Overloading crane
  • ✗ Structural failure (kegagalan struktur)
  • ✗ Tipping over (crane terbalik)
  • ✗ Dropped load (beban jatuh)
  • ✗ Cedera serius / fatality

Poin penting

  • ✓ Pakai Load Chart sesuai model crane & configuration.
  • ✓ Jangan angkat lebih dari nilai di chart.
  • ✓ Pertimbangkan radius, boom length, angle & configuration.
  • ✓ Jika ragu, pilih beban lebih rendah — bukan risiko lebih tinggi.

Tips angkatan aman
